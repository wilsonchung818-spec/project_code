# BA Speak · Days 42–60

每个 S：Q1 → A1 → Q2 → A2。Q 是对方，A 是你的回答。每个回答提供句型、替换规则和两个跨场景例句。

## Day 42 · Sprint Goal and Focus

### S1 · 对齐冲刺目标
你的角色：SM；对方：Developer

**Q1:** What's our main goal for this sprint?

**A1:** We want users to reset their passwords without calling support.

**Q2:** How will we know we've met that goal?

**A2:** We'll check the full reset flow against the agreed acceptance criteria.

#### A1 复用 · 说明目标
句型：We want [WHO] to [ACTION].

WHO 填人或团队；ACTION 填动词原形开头的动作。

- We want users to find their orders easily.
- We want our guests to feel at home.

#### A2 复用 · 说明核对方法
句型：We'll check [THING] against [STANDARD].

两处均为名词词组；against 表示对照标准。

- We'll check the results against the acceptance criteria.
- We'll check the bill against the prices on the menu.

### S2 · 临时插入需求
你的角色：SM；对方：Product owner

**Q1:** Can we fit this new request into the sprint?

**A1:** Let's check its value and impact with the team first.

**Q2:** What if it really can't wait?

**A2:** If it cannot wait, we can review the scope together while keeping the sprint goal.

#### A1 复用 · 先核对再行动
句型：Let's check [THING] with [PERSON] first.

THING 填待确认事项；PERSON 填需要沟通的人。

- Let's check the scope with the product owner first.
- Let's check the time with our friends first.

#### A2 复用 · 提出有条件的方案
句型：If [CONDITION], we can [ACTION].

CONDITION 填一般现在时完整句子；ACTION 填动词原形词组。

- If the tests pass, we can release the update.
- If the weather is good, we can eat outside.

### S3 · 跟进站会阻塞
你的角色：SM；对方：Developer

**Q1:** Why can't QA start the login test?

**A1:** We can't start the login test because the test account isn't ready.

**Q2:** Should we discuss the details now?

**A2:** Let's finish the daily scrum first, then have a quick chat with QA.

#### A1 复用 · 说明阻塞原因
句型：We can't [ACTION] because [REASON].

ACTION 填动词原形；REASON 填有主语和谓语的完整句子。

- We can't start testing because the account is locked.
- We can't leave yet because the taxi is late.

#### A2 复用 · 安排先后顺序
句型：Let's [FIRST] first, then [NEXT].

FIRST 和 NEXT 都填动词原形词组。

- Let's agree on the goal first, then discuss the details.
- Let's check the menu first, then book a table.

### S4 · 出门前找手机
