# 学校生活 100 词 · 口语学习 PWA

这是“小学英语高频词”系列的可安装样课。当前单词为 **book**，围绕“会认、会听、会搭配、会对话、会复习”设计。

## 体验内容

- 单词、音标、词义、自然拼读与跟读音频
- 3 个高频搭配，并可逐项完成
- 3 个图片沟通场景，每个场景都有完整问答、中文释义和替换练习
- 隐藏答案、交换角色、只听问题等渐进式口语训练
- 本机录音与回放；录音不会上传
- 第 1、2、7、14 天复习打卡，进度保存在当前设备
- 支持 Android、iPhone、iPad 添加到主屏幕，并可离线打开

## 本地预览

请通过本地静态服务器打开 `school-life-100/`，不要直接双击 HTML 文件。上线后由 GitHub Pages 自动发布。

## 生成应用图标

图标源文件是 `assets/icons/icon.svg`。需要重新生成 PNG 时，运行 `scripts/generate_icons.py`。
